Assumptions & model
  • DC: Thevenin R1||R2, VBE คงที่, β คงที่
  • AC: hybrid-π (gm = IC/VT, rπ = β/gm, ro = VA/IC)
  • Coupling caps รวมใน nodal analysis (5 nodes, complex)
  • Transient = small-signal sinusoidal steady-state
  • ไม่จำลอง clipping/saturation แบบ large-signal
  • Vin วัดที่ base หลัง Cin, Vout วัดที่ RL หลัง Cout

สมการที่ใช้
  • Fixed: IB = (VCC − VBE)/RB, IC = βIB, VCE = VCC − IC·RC
  • Emitter: IB = (VCC − VBE)/(RB + (β+1)RE)
  • Divider: VTH = VCC·R2/(R1+R2), RTH = R1||R2, IB = (VTH − VBE)/(RTH + (β+1)RE)
